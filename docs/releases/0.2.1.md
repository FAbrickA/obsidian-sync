# 0.2.1 — installable preview

- Install and update through BRAT using `FAbrickA/obsidian-sync`.
- Standalone installer assets include the full project and dependency licenses in `main.js`.
- Source publication uses an explicit file inventory and a clean Git history; private test data and local credentials are excluded.
- The sync protocol and merge algorithms are unchanged from 0.2.0.

Windows Obsidian 1.8.10 and Mail.ru were exercised during development. Linux and Android still require physical-device validation. This is a preview, not an all-platform stable release.

Use a separate empty WebDAV folder for the v2 repository. Do not point this plugin at an active Remotely Save folder or run both writers against the same destination.
